# E-Commerce-Sales-Analysis-PowerBI
An interactive E-Commerce Sales &amp; Performance Dashboard built using Microsoft Power BI. This project uses Power Query for data cleaning, DAX for KPI calculations, and interactive visualizations to analyze sales trends, product performance, customer demographics, sales channels, and regional insights.

# Project Overview:

This project focuses on analyzing e-commerce sales data using
Microsoft Power BI to understand sales performance, customer
behavior, product trends, and regional performance.
An interactive dashboard was developed to transform raw sales data into
meaningful business insights using Power Query, DAX measures, and
interactive visualizations.

## Project Objectives:
- Analyze overall e-commerce sales performance.
- Monitor key performance indicators (KPIs).
- Identify monthly sales trends and patterns.
- Analyze sales performance across different channels.
- Understand state-wise sales and order distribution.
- Compare product quantity sold by gender.
- Enable interactive data exploration through slicers.

## Tools & Technologies:
- Microsoft Power BI -- Dashboard development and data
  visualization.
- Power Query -- Data cleaning and transformation.
- DAX (Data Analysis Expressions) -- KPI calculations and
  measures.

 ## Data Cleaning & Transformation
- Checked and handled missing and invalid values.
- Removed unnecessary spaces and unwanted characters.
- Standardized text formatting and category values.
- Cleaned and standardized shipping city names.
- Verified data types and ensured consistency.
- Created calculated columns for month and age groups.

 ## Interactive Slicers
- Shipping City
- Product Size
- Age Group
- Order Status
- Product Category

 ## Dashboard Visualizations
 - Month-Wise Sales: Tracks monthly sales performance and trends.
 - Sales by Channel: Compares sales across Amazon, Myntra,
   Flipkart, Ajio, Nalli, Meesho, and other channels.
 - Sales by State: Visualizes geographical sales distribution
   across Indian states.
 - State-Wise Orders: Identifies states generating the highest
   number of orders.
 - Quantity Sold by Gender: Compares product quantities sold to
   women and men.

 ## Business Questions Explored
- Which sales channels contribute the most revenue?
- Which months have the highest and lowest sales?
- Which states generate the most sales and orders?
- How are product quantities distributed by gender?
- How do different product categories and customer age groups perform?
- What proportion of orders are cancelled or delivered?
